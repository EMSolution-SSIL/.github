# EMSolution-SSIL

**Open engineering tools for simulation and electric machine design.**

Science Solutions International Laboratory, Inc. (SSIL) develops
simulation software for computational electromagnetics, electric machine
design, optimization, and multiphysics CAE.

This GitHub organization hosts open-source tools, utilities, examples,
and documentation that support our simulation and engineering ecosystem.

## Products & Engineering Ecosystem

SSIL develops simulation software and engineering tools for electromagnetic field analysis, electric machine design, optimization, and multiphysics CAE.

## Open Source Projects

We develop and publish open-source tools for CAE and engineering workflows.

### Mesh and CAE Utilities

- [pyemsi](https://github.com/EMSolution-SSIL/pyemsi)  
  Python tools for EMSolution data conversion and interactive 3D visualization with VTK and PyVista.
  
- [ems_file_format_converter](https://github.com/EMSolution-SSIL/ems_file_format_converter)  
  File format conversion tools for CAE mesh and simulation data, including ATLAS, UNV, Femap NEU, and Gmsh MSH formats.

More open-source tools for mesh processing, mesh checking, and mesh morphing are under development.
